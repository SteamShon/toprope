# Lineage

Toprope continues problems the researcher worked on at a previous employer (Liner). This
project restarts from the problem definitions as personal research. The researcher states
that code and IP are not a concern; even so, the design here starts from written problem
statements and public sources, and claims nothing from prior work as measured evidence.

## Evidence levels carried over

- *Observed once, not measured*: top-tier coding agents lost direction on long tasks
  without planning and intervention; a 48-question owner interview (~1h) surfaced a
  mis-recorded agreement; three domains were set up this way.
- *Explicitly unmeasured*: whether the approach made anyone faster. M1–M2 exist to
  measure the parts of this that a personal project can measure.
