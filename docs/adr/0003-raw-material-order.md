# ADR-0003: Raw material order: system → records → interview → use

- Link: ① ② · Status: accepted · 2026-11-04 · decided by: SteamShon

## Decision
All four sources are supported. They are used in order of how easily they can be
automated: draft from existing systems, enrich from records, raise accuracy by interviewing
the owner, then improve through use. Each experiment measures every stage's contribution.
