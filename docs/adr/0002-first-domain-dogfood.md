# ADR-0002 — First domain: own coding-agent work, then a synthetic business domain

- Status: accepted · 2026-11-04 · decided by: SteamShon
- Evidence: notes/ko/2026-11-04-grilling.md

## Options
Own coding-agent work (dogfood) · synthetic business domain (refund, ad budget) · **both, dogfood first**

## Decision
Start with the researcher's own Claude Code / Codex work: the execution path (hooks) and the
history (transcripts) already exist, and the researcher is the target user. Generalize to a
synthetic business domain behind an MCP tool in M4.

## Consequences
Early results are n=1 for real use; the controlled M1 suite and M4 domain mitigate this.
