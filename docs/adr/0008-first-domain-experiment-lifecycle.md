# ADR-0008: First domain: experiment lifecycle

- Status: accepted · 2026-11-04 · decided by: SteamShon
- Supersedes: ADR-0002

## Options
**Experiment lifecycle** · code → product delivery · paid media budget operations

## Decision
Hypothesis → design → approval → launch → readout → ship/iterate/kill/escalate. It is the
exact pain named in the problem (turning work into a moved metric), every step is a
decision, it runs on synthetic data, and it later feeds thread C. Code → product delivery
becomes the second domain (M4) to test handoff and generality.

## Consequences
No real org: other roles are a scripted responder, and the data is synthetic.
